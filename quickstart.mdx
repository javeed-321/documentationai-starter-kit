## Prerequisites

<Callout kind="info">

Before you begin, create a free account at the dashboard and confirm your email address. You will also need a valid business email and basic company details.

</Callout>

## Create your first test payment

<Steps>
<Step title="Obtain API keys">

Log in to the dashboard. Navigate to Developers then API keys. Copy the publishable key and secret key shown for test mode. Store the secret key securely and never commit it to source control.

</Step>
<Step title="Create a test payment">

Use the secret key to authenticate an API request that creates a payment intent. The example below shows the minimal call required.

</Step>
</Steps>

<CodeGroup tabs="cURL">
```bash
curl https://api.example.com/v1/payment_intents \
  -u sk_test_YOUR_SECRET_KEY: \
  -d amount=2000 \
  -d currency=usd \
  -d "payment_method_types[]"=card
```
</CodeGroup>

## Configure webhooks

<Steps>
<Step title="Register an endpoint">

In the dashboard, go to Developers then Webhooks. Add an endpoint URL that listens for events such as payment_intent.succeeded. Stripe sends signed requests to this URL.

</Step>
<Step title="Verify signatures">

Add the webhook signing secret from the dashboard to your handler. Verify each incoming request before processing the event payload.

</Step>
</Steps>

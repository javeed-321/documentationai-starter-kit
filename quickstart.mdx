## Prerequisites

<Callout kind="info">
  You need an active Notion workspace with admin access. Enable the non-English content add-on from your workspace settings before proceeding.
</Callout>

## Enable language detection

<Steps>
  <Step title="Turn on detection" icon="settings">
    Navigate to Workspace settings and toggle Language detection to on. This activates automatic identification for all new pages.
  </Step>
  <Step title="Apply to existing pages" icon="check-circle">
    Select the pages you want to update and choose Apply language detection from the bulk actions menu.
  </Step>
</Steps>

## Add non-English content

Create your first international page with the following example.

<CodeGroup tabs="English,Japanese,French">
```markdown
# Project Update

This quarter we expanded into new markets.
```

```markdown
# プロジェクト更新

今四半期に新しい市場に拡大しました。
```

```markdown
# Mise à jour du projet

Ce trimestre nous nous sommes étendus sur de nouveaux marchés.
```
</CodeGroup>

## Configure display preferences

<Steps>
  <Step title="Set preferred languages" icon="globe">
    Go to your personal settings and add languages in priority order. Notion uses this list to choose the best display variant.
  </Step>
  <Step title="Test rendering" icon="eye">
    Open a page in multiple languages and verify that the correct version appears based on your preferences.
  </Step>
</Steps>

## Verify search results

Search for a term that appears in multiple languages. Results should surface the matching language variant first when your preferences align.

## Prerequisites

<Callout kind="info">
You need an active MetricsFlow account and an API key. Sign up at `https://dashboard.example.com` if you have not already.
</Callout>

## Connect an Event Source

<Steps>
  <Step title="Install the CLI" icon="download">
    Download and install the MetricsFlow CLI with the following command.

    ```bash
    curl -sSL https://install.example.com/metricsflow | sh
    ```
  </Step>
  <Step title="Configure your source" icon="settings">
    Create a minimal source configuration file named `source.yaml`.

    ```yaml
    source:
      type: kafka
      brokers:
        - kafka.example.com:9092
      topic: user-events
      apiKey: YOUR_API_KEY
    ```
  </Step>
  <Step title="Apply the configuration" icon="check-circle">
    Run the apply command to connect the stream.

    ```bash
    metricsflow apply -f source.yaml
    ```
  </Step>
</Steps>

## Define a Streaming Aggregation

<CodeGroup tabs="YAML,CLI">
```yaml
aggregation:
  name: events-per-minute
  source: user-events
  window: 1m
  groupBy: ["userId"]
  metrics:
    - name: eventCount
      type: count
```
```bash
metricsflow aggregation create \
  --name events-per-minute \
  --window 1m \
  --group-by userId \
  --metric eventCount:count
```
</CodeGroup>

## Query Live Metrics

Run your first query to see results within seconds.

```bash
metricsflow query \
  --aggregation events-per-minute \
  --since 5m
```

Expect sub-50 ms latency even at 50,000 events per second.

## Recent Releases

<Update label="2024-10-15" description="v2.0.0" tags={["breaking", "feature"]}>

## Breaking Changes

- Removed legacy `aggregate()` endpoint; use `computeAggregation()` instead.
- Renamed `eventRate` parameter to `eventsPerSecond` in all query objects.

## New Features

- Added `percentile()` and `distinctCount()` aggregation functions.
- Introduced support for windowed aggregations over > 1 billion records.

</Update>

<Update label="2024-09-20" description="v1.5.0" tags={["feature"]}>

## Performance Improvements

- Reduced average latency to `<50ms` at 50000 events per second.
- Increased throughput by 40% through optimized partitioning.

## New Features

- Added `sumIf()` and `avgIf()` conditional aggregation functions.

</Update>

<Update label="2024-08-10" description="v1.4.0" tags={["bugfix"]}>

## Bug Fixes

- Fixed race condition in real-time aggregation pipeline.
- Corrected overflow handling for counts exceeding 1 billion records.

</Update>

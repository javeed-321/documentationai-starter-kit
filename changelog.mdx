## Recent updates

<Update label="2026-06-18" description="v3.8.0" tags={["feature"]}>

## New AI agent capabilities

- Added agent actions for routine workspace tasks.
- Improved routing so agents can assign work to the right teammate faster.
- Expanded report generation for recurring status updates and summaries.

## Calendar and mail integrations

- Tightened calendar linking for faster event context in workspace views.
- Improved mail-aware workflows so related work is easier to surface.
- Reduced friction when moving between messages, tasks, and notes.

## Performance and UI updates

- Improved page load speed across large workspaces.
- Refined navigation spacing and panel behavior.
- Lowered latency in search and view switching.

</Update>

- Added clearer admin controls for workspace-wide settings.

- Improved transcript quality and note structure.
- Reduced editing time after meetings.

## Overview

Your store theme sets the first impression for every visitor. Shopify themes come ready to use, yet you can adjust colors, fonts, and layouts until the design matches your brand exactly. The theme editor handles most changes without code, while Sidekick AI speeds up the tricky parts. This guide walks you through installation, custom CSS, AI assistance, and mobile checks so you finish faster.

## Install a Theme

Pick a theme from the Shopify Theme Store that fits your industry and style. Once you decide, installation takes only a few clicks.

<Steps>
  <Step title="Choose your theme">
    Browse the Theme Store and click the theme you like. Review the demo to confirm it supports your product types.
  </Step>
  <Step title="Install the theme">
    Click Try theme, then confirm. Shopify adds the theme to your store under Online Store > Themes.
  </Step>
  <Step title="Publish the theme">
    Click the three-dot menu next to the new theme and select Publish. Your store updates immediately.
  </Step>
</Steps>

<Callout kind="tip">
  Keep your current theme published until the new one looks right. You can switch back anytime.
</Callout>

## Add Custom CSS

Need a small style tweak the editor cannot handle? Add custom CSS in the theme settings.

<Tabs>
  <Tab title="Theme editor">
    Open Online Store > Themes > Customize. Click Theme settings, then Custom CSS. Paste your rules and save.
  </Tab>
  <Tab title="Code editor">
    From the theme list, click Actions > Edit code. Open assets/theme.css. Add your CSS at the bottom.
  </Tab>
</Tabs>

<CodeGroup tabs="CSS example">
```css
/* Make buttons stand out */
.button {
  background-color: #000;
  color: #fff;
  border-radius: 4px;
}
```
</CodeGroup>

## Use Sidekick AI Assistance

Sidekick answers questions about your theme while you work. Open the AI helper from the theme editor sidebar.

<Expandable title="Ask Sidekick for layout help" default-open="false">
  Type a clear request such as "Make the product grid two columns on mobile." Sidekick suggests the exact setting or code change.
</Expandable>

<Expandable title="Generate section code" default-open="false">
  Ask Sidekick to create a new section. Copy the output, paste it into a new file in the code editor, and save.
</Expandable>

## Optimize for Mobile

Most shoppers browse on phones. Check every change on the mobile preview before you publish.

<Card title="Mobile checklist" icon="smartphone" href="#">
  - Test navigation menus on small screens
  - Confirm images load quickly
  - Verify buttons are large enough to tap
</Card>

## Best Practices

- Save a duplicate of your theme before major edits.
- Use consistent colors and fonts across all sections.
- Re-check mobile view after each CSS change.
- Let Sidekick handle repetitive tasks so you focus on brand decisions.

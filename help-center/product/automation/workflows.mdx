## How workflows run

A workflow is a set of rules — **when** something happens, **then** take an
action. They run automatically on every matching conversation.

<Steps>
  <Step title="Choose a trigger">
    For example, "a new conversation is created from the chat channel."
  </Step>
  <Step title="Add conditions">
    Narrow it down — by tag, channel, or customer attribute.
  </Step>
  <Step title="Define actions">
    Assign a team, send an auto-reply, or set a priority.
  </Step>
</Steps>

<Callout kind="info" collapsed="false">
  Workflows run top to bottom — order them from most to least specific.
</Callout>

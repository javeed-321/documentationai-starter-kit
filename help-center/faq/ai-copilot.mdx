## Why are AI Copilot suggestions not matching the conversation?

If the suggestions feel off, this page helps you check permissions, knowledge sources, and the metrics that show how well AI Copilot is performing.

## Check suggestion accuracy first

AI Copilot suggestions work best when the conversation has clear context and the connected knowledge base is current. If the suggestions look unrelated, review these common causes:

- The agent is missing access to the right knowledge articles.
- The connected knowledge source is incomplete or outdated.
- The conversation does not contain enough context yet.
- The assistant is not allowed to use the data you expect.

<Callout kind="tip">
Start with one recent conversation and compare the suggestions against the articles and notes the agent could access. This makes it easier to spot a permissions or content issue.
</Callout>

## How do I troubleshoot inaccurate suggestions?

<Steps>
  <Step title="Confirm the agent can access the right content" icon="shield">
    Make sure the agent has permission to view the knowledge base articles, macros, and internal guidance that AI Copilot should use.

  </Step>
  <Step title="Check the connected knowledge sources" icon="database">
    Review which knowledge sources are connected and confirm they contain current, relevant content for the issue type.

  </Step>
  <Step title="Test with a live conversation" icon="zap">
    Open a recent support session and watch how suggestions change as the conversation gains more context.

  </Step>
  <Step title="Review the performance metrics" icon="bar-chart">
    Compare suggestion acceptance, agent edits, and resolution outcomes to see whether the assistant is helping or missing the mark.

  </Step>
</Steps>

## What agent permissions affect AI Copilot?

AI Copilot can only suggest content the agent is allowed to use. If permissions are too narrow, the assistant may look less accurate than it really is.

| Permission area | What it affects | What to check |
| --- | --- | --- |
| Knowledge access | Which articles and guidance can be suggested | Confirm the agent can view the needed content |
| Workspace access | Which tools and session data are available | Make sure the agent has access to the right workspace |
| Role settings | What the agent can see or edit | Review role-based restrictions |
| Channel access | Whether suggestions appear in the active support channel | Confirm the session is in a supported channel |

## Where does AI Copilot get its knowledge?

AI Copilot uses the content and context you connect to it. That usually includes:

- Help articles and internal knowledge content
- Conversation history and current session details
- Approved support workflows and guidance
- Other connected sources your team has enabled

<Callout kind="info">
If you update your knowledge base, give the assistant time to reflect the changes, then test the same question again in a new session.
</Callout>

## Which metrics should I review?

Use performance metrics to tell whether the assistant is actually helping agents. The most useful signals are:

| Metric | What it tells you |
| --- | --- |
| Suggestion acceptance rate | How often agents use the suggested response or action |
| Edit rate | How often agents change a suggestion before sending it |
| Resolution speed | Whether sessions close faster with assistance |
| Quality outcomes | Whether the assistant helps agents give more consistent answers |
| Escalation rate | Whether unclear suggestions lead to more handoffs |

## When should I expect better results?

Use the assistant in conversations where the issue is common, the wording is clear, and the knowledge base has strong coverage. Results are usually weaker when:

- The topic is new or rare
- The source content is missing
- The conversation is vague
- Permissions limit the available context

## Common questions

<Expandable title="Why does AI Copilot suggest the wrong article?" default-open="false">
The most common reasons are outdated content, limited permissions, or a mismatch between the live conversation and the knowledge source. Check each of those before making changes to the assistant itself.

</Expandable>

<Expandable title="Can I control what AI Copilot can use?" default-open="false">
Yes. You can limit access through agent permissions and by choosing which knowledge sources are connected. Use the smallest set of content that still covers the issues your team handles.

</Expandable>

<Expandable title="How do I know if it is helping agents?" default-open="false">
Review suggestion acceptance, edit rate, resolution speed, and escalation rate together. One metric on its own can be misleading.

</Expandable>

## Still stuck?

If the suggestions still do not make sense, contact Zendesk support with a few example conversations, the knowledge sources in use, and the metrics you reviewed.

## Account and Site Setup

<ExpandableGroup>
  <Expandable title="How do I create my first Help Center?" default-open="true">
    Sign in to your Zendesk account, open the Admin Center, and select Help Center. Click Create and choose a theme. Add your brand colors and logo, then publish.
  </Expandable>
  <Expandable title="What domain should I use for the site?">
    Use a custom subdomain such as support.yourcompany.com. You can map it in the Branding section under Domains.
  </Expandable>
</ExpandableGroup>

## User Roles and Permissions

<ExpandableGroup>
  <Expandable title="Who can edit articles by default?" default-open="true">
    Agents with Help Center Manager or Administrator roles can create and publish content. End users can only view published articles unless you grant them contributor access.
  </Expandable>
  <Expandable title="How do I restrict editing to specific teams?">
    Go to People and add agents to custom groups. Then set article permissions so only those groups can edit sections or categories.
  </Expandable>
</ExpandableGroup>

## Content Migration

<ExpandableGroup>
  <Expandable title="Can I import articles from another platform?" default-open="true">
    Yes. Export your existing content as HTML or Markdown, then use the bulk import tool in Admin Center. Map categories during import to keep structure intact.
  </Expandable>
  <Expandable title="What happens to images and attachments during migration?">
    Upload images separately to your Zendesk assets folder first. Then update any image links in the imported Markdown files before publishing.
  </Expandable>
</ExpandableGroup>

## Mobile and Multilingual Support

<ExpandableGroup>
  <Expandable title="Does the Help Center work on phones and tablets?" default-open="true">
    The default theme is responsive and works on all screen sizes. Test it by opening your site on a mobile browser or use the Zendesk mobile app to preview.
  </Expandable>
  <Expandable title="How do I add another language?">
    In Guide settings, enable additional languages. Translate articles in the editor, then set a default language for visitors based on their browser settings.
  </Expandable>
</ExpandableGroup>

## Get started with AI agents

You need AI agents that resolve customer issues on their own. This guide walks you through configuration, training, and deployment so your agents start handling tickets, chats, and calls right away.

## Configure your first agent

Follow these steps to set up an agent that works across channels.

<Steps>
  <Step title="Open the AI Agents section">
    In Zendesk, go to Admin and select AI Agents. Click Create Agent.
  </Step>
  <Step title="Choose channels and scope">
    Select the channels your agent will use, such as email, chat, voice, or messaging. Define the issue types it should handle.
  </Step>
  <Step title="Set resolution rules">
    Add the outcomes you want, such as close ticket, escalate to human, or create follow-up task. Save the configuration.
  </Step>
</Steps>

## Train the self-improving model

Zendesk agents learn from every resolved interaction. After you deploy the agent, review the first 50 resolved tickets in the Training tab. Mark any incorrect resolutions so the model updates its behavior automatically.

<Callout kind="tip">
  Let the agent run for at least one week before you adjust training data. This gives the model enough examples to improve accuracy.
</Callout>

## Apply AI governance

Control how the agent uses customer data and makes decisions.

| Setting              | Options                          | Recommended use                     |
|----------------------|----------------------------------|-------------------------------------|
| Data access          | Full, Limited, None              | Start with Limited for new agents   |
| Decision logging     | On, Off                          | Keep On for audit and compliance    |
| Human review trigger | High confidence only, Always     | Use Always during initial rollout   |

Turn on these controls in the Governance panel before you publish the agent.

## Set up resolution workflows

Link your agent to existing workflows so it can act without extra steps.

- Create a trigger that routes new tickets to the agent when the subject matches common issues.
- Add a condition that sends high-value customers straight to a human agent.
- Test the full flow with a sample ticket before you enable it for live traffic.

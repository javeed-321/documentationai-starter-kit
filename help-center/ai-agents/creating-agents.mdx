---
title: Create and Deploy AI Agents
description: Design autonomous agents that resolve complex issues on any channel.
---

You need agents that handle tickets, chats, and calls on their own. This page shows how to build, train, and launch them in Zendesk.

## Open the Agent Builder

<Steps>
  <Step title="Go to the Resolution Platform">
    Sign in to Zendesk and select AI from the main menu.

  </Step>
  <Step title="Create a new agent">
    Click New Agent, enter a name, and choose the channels it will cover.

  </Step>
  <Step title="Save and continue">
    Click Create. The builder opens with default settings.

  </Step>
</Steps>

## Train intents

Add example phrases so the agent recognizes what customers want.

- List 10–15 phrases for each common request.
- Mark the correct intent for each phrase.
- Run the test set and review accuracy.

<Callout kind="tip">
  Retrain after every major change in your product or policy.
</Callout>

## Set escalation rules

Tell the agent when to hand off to a human.

| Condition              | Action                  | Channel     |
|------------------------|-------------------------|-------------|
| Confidence below 70 %  | Escalate to agent       | All         |
| Customer says "speak to human" | Immediate transfer | Chat, Voice |
| Issue involves refund  | Route to billing team   | Ticket      |

## Test before you deploy

<Expandable title="How do I run a test conversation?">
  Open the preview panel, type sample messages, and check the agent's replies and escalation decisions.

</Expandable>
<Expandable title="What happens if the agent makes a mistake?">
  Review the interaction log, mark the error, and add the corrected phrase to training.

</Expandable>

## Deploy the agent

<Steps>
  <Step title="Choose rollout scope">
    Start with a single channel or a small group of customers.

  </Step>
  <Step title="Turn on the agent">
    Click Deploy. Monitor the first 24 hours of activity.

  </Step>
</Steps>

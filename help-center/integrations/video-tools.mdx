---
title: Video Conferencing Tools
description: Automatically generate Zoom, Google Meet, or Microsoft Teams links.
---

Calendly can automatically add a video link to every event, but you must connect your conferencing tool first. This page shows you how to set that up for Zoom, Google Meet, and Microsoft Teams, plus how to use a custom link.

## Supported tools

| Tool              | How the link is created          |
|-------------------|----------------------------------|
| Zoom              | Calendly creates a new meeting   |
| Google Meet       | Uses your Google account         |
| Microsoft Teams   | Creates a new meeting            |
| Custom            | You paste any link you choose    |

## Connect Zoom

<Steps>
  <Step title="Open event type settings">
    Go to the event type you want to update and click the pencil icon.

  </Step>
  <Step title="Choose conferencing">
    In the Location section, select Zoom.

  </Step>
  <Step title="Authorize access">
    Sign in with your Zoom account when prompted and allow Calendly to create meetings.

  </Step>
</Steps>

<Callout kind="tip">
  You only need to authorize once. Calendly keeps the connection for future events.
</Callout>

## Connect Google Meet or Microsoft Teams

<Steps>
  <Step title="Select the tool">
    Edit your event type, then pick Google Meet or Microsoft Teams from the Location menu.

  </Step>
  <Step title="Sign in">
    Log in with the Google or Microsoft account that holds your calendar.

  </Step>
  <Step title="Save changes">
    Click Save. A new meeting link will now appear on every booking.

  </Step>
</Steps>

## Use a custom conferencing link

If you prefer another tool, choose Custom and paste the link you want every invitee to receive.

<Expandable title="What happens if my account is disconnected?">
  Calendly shows a warning on the event type. Reconnect the same account to restore automatic links.
</Expandable>

<Expandable title="Can I use different tools for different event types?">
  Yes. Each event type keeps its own setting, so one event can use Zoom while another uses Teams.
</Expandable>

Still stuck? Contact Calendly support from the Help menu in your account.

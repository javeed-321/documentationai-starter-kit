## Overview

Calendly adds a video link to every scheduled event so you never hunt for a meeting URL again. Connect your preferred tool once and Calendly handles the rest.

Choose the option that matches how you work.

<Callout kind="info">
  You need an active account with the video service before you connect it in Calendly.
</Callout>

## Zoom integration

Connect Zoom to create a unique meeting room for each booking.

<Tabs>
  <Tab title="Personal" icon="user">
    1. Go to your Calendly event type.
    2. Open the Location section.
    3. Select Zoom and sign in with your Zoom account.

    Calendly now adds a Zoom link automatically.
  </Tab>
  <Tab title="Team" icon="users">
    Admins can connect a shared Zoom account so every team member uses the same integration.
  </Tab>
</Tabs>

## Microsoft Teams meetings

Teams users follow a similar path.

<Steps>
  <Step title="Connect your account">
    In the event type editor, pick Microsoft Teams as the location and sign in.
  </Step>
  <Step title="Confirm the link">
    Save the event type. Test with a sample booking to see the Teams link appear.
  </Step>
</Steps>

## Custom conferencing

Need a different tool? Add any link manually or use a custom template.

<Expandable title="Add a custom link" default-open="false">
  Paste your preferred meeting URL into the location field. Calendly keeps the same link for every booking of that event type.
</Expandable>

## Best practices

- Test the full flow with a sample booking before sharing the link with others.
- Keep your video account logged in so Calendly can create rooms without interruption.
- Update the connection if you change video providers.

<ExpandableGroup>
  <Expandable title="Link not appearing?" default-open="false">
    Reconnect the integration in your Calendly settings and save the event type again.
  </Expandable>
  <Expandable title="Need a different room each time?" default-open="false">
    Most connected tools already create a fresh room per booking. Custom links stay the same unless you edit them.
  </Expandable>
</ExpandableGroup>

You need to connect Mailchimp to apps like WooCommerce, WordPress, or social platforms. This page shows the fastest way to link them through the app directory, API keys, and data mapping.

## Find apps in the directory

Open Mailchimp and go to the Integrations section. Search for the app you want to connect.

- WooCommerce appears under e-commerce tools.
- WordPress shows under website builders.
- Social platforms list under marketing channels.

Select the app to start the setup.

## Get your API key

Every connection needs an API key from Mailchimp.

<Steps>
  <Step title="Open API keys page">
    Go to your account settings and select API keys.

  </Step>
  <Step title="Create a new key">
    Click Create Key and give it a name that describes the app.

  </Step>
  <Step title="Copy the key">
    Copy the full key right away. You cannot view it again later.

  </Step>
</Steps>

<Callout kind="alert">
  Store the key in a safe place. Never share it in public channels or support tickets.
</Callout>

## Map your data

After you enter the API key, choose which fields to sync.

| App          | Common fields to map          | Notes                     |
|--------------|-------------------------------|---------------------------|
| WooCommerce  | Email, order total, products  | Sync purchase history     |
| WordPress    | Email, name, signup date      | Use for newsletter forms  |
| Social       | Username, engagement score    | Pull audience interests   |

Match each field on the left with the correct Mailchimp audience field on the right. Save the mapping before you finish.

## Test the connection

Add a test contact in the connected app. Check that it appears in your Mailchimp audience within a few minutes.

## Common questions

<Expandable title="What if the app does not appear in the directory?">
  Use the API key method instead. Most apps accept a direct key connection even if they are not listed.

</Expandable>

<Expandable title="Can I connect more than one app at once?">
  Yes. Repeat the steps for each app. Each connection uses its own API key.

</Expandable>

Still stuck? Contact Mailchimp support through the Help menu in your account.

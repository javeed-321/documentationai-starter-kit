## Overview

You can connect Mailchimp to the tools you already use. This keeps your audience data consistent and saves time on manual updates. The platform supports direct API access, automated data sync, and real-time webhooks so changes flow both ways without extra steps.

Start with the integrations directory inside your account. Search for the app you need, then follow the guided setup. Most connections finish in a few minutes.

## API Connections

Use the Mailchimp API to pull or push data from any custom system. Generate an API key in your account settings, then include it in each request header.

<Callout kind="tip">
Store the key securely and rotate it every 90 days.
</Callout>

```javascript
});
```

## Best Practices

- Test every new connection with a small audience first.
- Map fields carefully so no data is overwritten.
- Monitor the activity log after setup to catch errors early.

<Expandable title="Need help troubleshooting?" default-open="false">
Check that your API key has the correct scopes. If a webhook fails, review the payload in the logs and confirm your endpoint returns a 200 status quickly.
</Expandable>

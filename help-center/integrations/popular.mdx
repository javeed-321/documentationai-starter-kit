You need Mailchimp to share data with tools like WooCommerce, WordPress, and Zapier. This page shows how to set up the most common connections for API access, third-party apps, and automatic data sync.

## Popular integrations at a glance

| Tool         | Connection type     | What syncs                     |
|--------------|---------------------|--------------------------------|
| WooCommerce  | Plugin + API        | Orders, products, customers    |
| WordPress    | Plugin              | Forms, subscribers, posts      |
| Zapier       | No-code connector   | Contacts, campaigns, tags      |
| 300+ others  | API or app directory| Varies by app                  |

## Connect WooCommerce

<Steps>
  <Step title="Install the plugin">
    Log in to your WordPress dashboard and search for the official Mailchimp plugin in the plugin directory.

  </Step>
  <Step title="Connect your account">
    Enter your Mailchimp API key in the plugin settings and authorize the connection.

  </Step>
  <Step title="Choose what to sync">
    Select the stores, products, and customer data you want to send to Mailchimp.

  </Step>
</Steps>

<Callout kind="tip">
  Test the connection with a single order before turning on full sync.
</Callout>

## Connect WordPress

<Steps>
  <Step title="Add the plugin">
    From your WordPress admin, install the Mailchimp for WordPress plugin and activate it.

  </Step>
  <Step title="Link your audience">
    Paste your Mailchimp API key and map your signup forms to the correct audience.

  </Step>
  <Step title="Enable data sync">
    Turn on options to add new subscribers and update contact details automatically.

  </Step>
</Steps>

## Connect Zapier

<Steps>
  <Step title="Create a Zap">
    In Zapier, choose Mailchimp as the action app and select the trigger from your other tool.

  </Step>
  <Step title="Map fields">
    Match contact fields, tags, and merge tags between the two apps.

  </Step>
  <Step title="Turn on the Zap">
    Test the workflow, then enable it to run automatically.

  </Step>
</Steps>

## API connections

Use the Mailchimp API when you need custom code or advanced control. Generate an API key in your account settings, then send requests to the audience or campaign endpoints. Keep your key secure and rotate it every 90 days.

<Expandable title="How do I find my API key?">
  Go to your Mailchimp account, click your profile icon, choose Account, then navigate to Extras and API keys.

</Expandable>

<Expandable title="What happens if sync stops working?">
  Check your API key, confirm the connected app still has permission, and review error logs in the integration settings.

</Expandable>

Still stuck? Contact Mailchimp support through the in-app help chat.

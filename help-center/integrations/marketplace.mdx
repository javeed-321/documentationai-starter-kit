## Overview

Zendesk Marketplace gives you access to more than 1,800 apps and partner integrations. You connect these tools directly to the Resolution Platform so tickets, chats, and calls flow into the systems your team already uses. The result is fewer manual steps and faster resolutions across every channel.

## App Installation

Install apps from the Marketplace in just a few clicks. Choose an app, review the permissions it needs, and confirm the connection to your Zendesk account.

<Tabs>
  <Tab title="Admin Center" icon="settings">
    Open Admin Center, go to Marketplace, search for the app, then click Install.

    <Callout kind="tip">
      Log in as an administrator before you start so the app can request the right scopes.
    </Callout>
  </Tab>
  <Tab title="Marketplace Site" icon="external-link">
    Visit the Marketplace listing, click Install, and sign in with your Zendesk credentials.
  </Tab>
</Tabs>

## Data Sync

Once installed, most apps keep records in sync automatically. You decide which fields map between Zendesk and the connected service.

<CodeGroup tabs="JSON,CSV">
```json
{
  "sync": {
    "direction": "bidirectional",
    "fields": ["subject", "status", "custom_field_123"]
  }
}
```
```csv
field_zendesk,field_external,mode
subject,title,both
status,state,import
```
</CodeGroup>

## Best Practices

- Review every app's permission list before installation.
- Start with one integration, test the data flow, then add the next.
- Use the built-in audit log to track which apps touch which records.
- Update apps regularly so you receive the latest security fixes and features.

You need to connect external apps to Zendesk to automate ticketing and sync customer data. This page shows you how to install apps, create API actions, and set up data sync.

## Installing an app from the marketplace

<Steps>
  <Step title="Open the marketplace">
    In Zendesk Admin Center, go to Marketplace.

  </Step>
  <Step title="Search and select">
    Enter the app name or category, then click the app you want.

  </Step>
  <Step title="Install and authorize">
    Click Install, choose your account, and grant the required permissions.

  </Step>
</Steps>

<Callout kind="info">
  Some apps require an admin to approve the installation first.

</Callout>

## Building custom API actions

Create actions that trigger when tickets update or new contacts arrive.

<Expandable title="How do I create a custom action?">
  1. Go to Admin Center > Integrations > Actions.
  2. Click Create Action and choose API.
  3. Enter the endpoint URL and map the fields you need.
  4. Test the action with a sample ticket.

</Expandable>

## Setting up data sync

Choose how often Zendesk pulls or pushes data with connected apps.

| Sync type   | When it runs          | Best for                     |
|-------------|-----------------------|------------------------------|
| Real-time   | Instantly on change   | Live chat and urgent tickets |
| Scheduled   | Every 15 minutes      | Bulk contact updates         |
| Manual      | Only when you trigger | One-time data imports        |

<Callout kind="tip">
  Start with scheduled sync to avoid hitting rate limits on the connected app.

</Callout>

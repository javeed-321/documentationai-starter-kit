## Overview

Calendly sends automatic reminders so invitees arrive prepared and you avoid last-minute surprises. You control timing, wording, and what happens when someone misses a meeting. Set these options once and Calendly handles the rest.

## Set reminder timing

Choose when reminders go out. Most teams use a 24-hour email plus a 1-hour SMS. You can add a post-meeting thank-you note or a 48-hour follow-up.

<Callout kind="tip">
  Start with the defaults, then adjust one timing at a time so you can see what improves attendance.
</Callout>

## Customize messages

Write your own subject lines and body text. Keep them short, friendly, and include the meeting details Calendly already knows.

<Tabs>
  <Tab title="Email" icon="mail">
    Personalize the greeting and add a single call-to-action link.
  </Tab>
  <Tab title="SMS" icon="message-circle">
    Limit to two short sentences and the meeting time.
  </Tab>
</Tabs>

## Handle no-show workflows

Create a separate sequence that triggers only when the calendar event ends without a check-in.

<Expandable title="No-show options" default-open="false">
  - Send a polite reschedule link  
  - Notify only the host  
  - Add the contact to a follow-up list

</Expandable>

## Examples

Here is a simple 24-hour email reminder:

```markdown
Subject: Quick reminder — our call is tomorrow at 2:00 PM

Hi {{name}},
Looking forward to speaking with you. Click here if you need to make any changes.
```

## Best practices

- Test every new message with your own calendar first.
- Keep SMS under 160 characters so nothing gets split.
- Review no-show rates monthly and tweak timing if needed.

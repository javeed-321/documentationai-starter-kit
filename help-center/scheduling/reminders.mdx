---
title: Automating Reminders
description: Configure email and SMS notifications for hosts and invitees.
---

Calendly sends automatic reminders by default, but you can customize the timing, content, and channels so hosts and invitees always know when a meeting is coming up.

## Set up email reminders

Email reminders go out to both the host and invitee at the times you choose.

<Steps>
  <Step title="Open your event type">
    Go to Event Types and select the event you want to edit.

  </Step>
  <Step title="Turn on reminders">
    Click the Notifications tab, then toggle Email reminders on.

  </Step>
  <Step title="Choose when to send">
    Pick the intervals that fit your workflow. Common choices are 24 hours and 1 hour before the event.

  </Step>
  <Step title="Edit the template">
    Click the pencil icon next to each reminder. Replace the default text with your own message, then save.

  </Step>
</Steps>

## Add SMS reminders

SMS reminders reach invitees even when they miss email.

<Callout kind="info">
  SMS is available on Standard, Teams, and Enterprise plans. You must first connect a phone number in Account Settings.

</Callout>

<Steps>
  <Step title="Enable SMS">
    In the same Notifications tab, toggle SMS reminders on.

  </Step>
  <Step title="Set timing">
    Choose when the text message should arrive. You can use the same intervals as email or different ones.

  </Step>
  <Step title="Write the message">
    Keep the text under 160 characters. Include the meeting time and a link to reschedule if needed.

  </Step>
</Steps>

## Create follow-up workflows

Follow-up messages help after the meeting ends.

| Workflow | Trigger | Default action |
| --- | --- | --- |
| Thank-you email | Event ends | Sends a simple thank-you note |
| Feedback request | 2 hours after event | Asks invitees to rate the meeting |
| No-show sequence | Event starts with no join | Sends a reschedule link to the invitee |

Turn these on in the Workflows section of your event type. You can edit the messages the same way you edit reminders.

## Common questions

<Expandable title="Can I send different reminders to hosts and invitees?">
  Yes. Create separate reminder rules for each recipient type inside the Notifications tab.

</Expandable>

<Expandable title="What happens if an invitee reschedules?">
  Calendly automatically cancels the old reminders and sends new ones based on the updated time.

</Expandable>

<Expandable title="Can I turn reminders off for one event only?">
  Yes. Open that event type, go to Notifications, and toggle reminders off. Your other event types stay unchanged.

</Expandable>

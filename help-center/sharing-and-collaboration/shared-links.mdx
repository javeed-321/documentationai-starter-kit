## Overview

Dropbox makes it simple to share files and folders with anyone. You create a link, choose who can access it, and control what they can do. This approach works well when collaborators need quick access without full folder permissions.

Shared links stay secure through built-in controls. You decide whether recipients can view or edit content. You can also add passwords or set expiration dates to limit access.

## Setting Link Permissions

Choose permissions when you create the link. View-only access prevents changes. Edit access lets recipients update files directly in Dropbox.

<Tabs>
  <Tab title="View only" icon="eye">
    Recipients can open and download files but cannot make changes. This option suits clients or external partners who need to review work.

  </Tab>
  <Tab title="Can edit" icon="edit">
    Recipients can modify files inside the shared folder. Use this setting for team members who actively contribute.

  </Tab>
</Tabs>

## Sharing Large Files

Dropbox supports files up to 50 GB through shared links. Recipients download the content without needing an account in most cases.

<Callout kind="tip">
  Large video or design files transfer smoothly. Recipients receive a direct download link that works on any device.

</Callout>

## Controlling Access

Add extra protection with passwords and expiration dates. These controls help when sharing sensitive material.

<Expandable title="Add a password" default-open="false">
  Open the share settings for your link. Enter a password that recipients must type before they can view the content. Share the password separately for better security.

</Expandable>

<Expandable title="Set an expiration date" default-open="false">
  Choose a date when the link stops working. This feature automatically revokes access after the chosen period ends.

</Expandable>

## Best Practices

- Test the link yourself before sending it.
- Update permissions if team membership changes.
- Remove the link when the project ends to stop further access.
- Use expiration dates for any content that contains private information.

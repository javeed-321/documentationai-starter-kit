## Overview

Team Folders give your group a single place to store and work on files together. Everyone sees the latest version, and you can comment or request approvals without leaving Dropbox.

## Create a team folder

Follow these steps to set up your shared space.

<Steps>
  <Step title="Open Dropbox">
    Sign in and go to the folder you want to share.
  </Step>
  <Step title="Share with your team">
    Click Share, enter team member emails, and choose Can edit.
  </Step>
  <Step title="Turn it into a Team Folder">
    Select Make this a Team Folder so ownership stays with the group.

  </Step>
</Steps>

<Callout kind="tip">
  Add a short description when you create the folder so new members know its purpose right away.
</Callout>

## Edit files in real time

Open any file inside the Team Folder. Changes appear for everyone within seconds.

<Tabs>
  <Tab title="Desktop" icon="monitor">
    Double-click the file to open it in the native app. Edits sync automatically.
  </Tab>
  <Tab title="Web" icon="globe">
    Click the file name to open the web preview and edit inline.
  </Tab>
</Tabs>

## Add comments and approvals

Select a file or folder, then click Comment. Tag teammates to ask questions or request sign-off.

## Best practices

- Keep folder names short and clear so everyone finds content fast.
- Set permissions at the folder level instead of individual files.
- Review shared links every quarter and remove access for former members.

<ExpandableGroup>
  <Expandable title="What if someone leaves the team?" default-open="false">
    Remove them from the Team Folder in the sharing settings. Their access ends immediately.
  </Expandable>
  <Expandable title="Can I restore an older version?" default-open="false">
    Yes. Every edit is saved in version history for 30 days on standard plans.
  </Expandable>
</ExpandableGroup>

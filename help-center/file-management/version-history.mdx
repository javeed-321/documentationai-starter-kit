## Overview

Dropbox keeps copies of your files so you can go back to an earlier version or bring back something you deleted. This helps when you make a mistake or lose work. You can view and restore versions from the web, desktop app, or mobile.

## Version Retention

Dropbox stores previous versions for a set time based on your plan. Free accounts keep versions for 30 days. Paid plans extend that to 180 days or more. You can restore any saved version without affecting the current file.

## File Recovery

Deleted files stay in the trash for 30 days on free plans and longer on paid ones. You can restore them from the trash folder or use the recovery tool to search for older copies.

<Tabs>
  <Tab title="Web" icon="globe">
    Open dropbox.com, find the file, click the three dots, then choose Version history.
  </Tab>
  <Tab title="Desktop" icon="monitor">
    Right-click the file in your Dropbox folder and select View previous versions.
  </Tab>
</Tabs>

## Smart Sync

Smart Sync lets you see all files without using full space on your computer. Files marked online-only still keep their version history in the cloud. You can restore versions even when the local copy is not downloaded.

<Callout kind="tip">
  Turn on Smart Sync in settings if you work across multiple devices.
</Callout>

## Examples

A team member overwrote a shared presentation. You open the file's version history, pick the version from yesterday, and restore it in one click.

<Expandable title="What if the version I need is older than my plan allows?">
  Contact support. They may help recover it if it is still in the system.
</Expandable>

## Best Practices

- Check version history before you delete or replace important files.
- Share links instead of copies so everyone works from the same file.
- Review your plan's retention period so you know how far back you can go.

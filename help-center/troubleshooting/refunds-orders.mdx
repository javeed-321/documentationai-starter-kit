## Common Refund and Order Issues

<Expandable title="Refund button is disabled after order delivery">

You see the refund option grayed out in the order details.

**Problem**  
The refund button shows as unavailable even though the customer requested a return.

**Cause**  
Shopify automatically locks refunds once the order reaches the 90-day fulfillment window.

**Fix**  
1. Open the order in your Shopify admin.  
2. Go to the Timeline section and add a manual note with the refund amount.  
3. Contact Shopify Support through the Help menu and reference case ID starting with `RF-`.

</Expandable>

<Expandable title="Chargeback dispute shows as 'Evidence required'">

A dispute appears in the Payments section with status Evidence required.

**Problem**  
You receive an email stating "Action needed on chargeback for order #1001".

**Cause**  
The payment processor needs supporting documents within 7 days of the alert.

**Fix**  
1. Download the order receipt and shipping confirmation from the order page.  
2. Upload both files in the dispute form before the deadline.  
3. Add a short note explaining the delivery date shown on the tracking link.

</Expandable>

<Expandable title="Shipping label error: 'Invalid weight value'">

Creating a label fails with the exact message Invalid weight value.

**Problem**  
The label preview never loads and the checkout shows this error.

**Cause**  
The product weight field contains a zero or is left blank for physical items.

**Fix**  
1. Edit the product and enter a weight greater than 0.01 lb.  
2. Save the change, then return to the order and regenerate the label.  
3. If the error remains, refresh the shipping rates section.

</Expandable>

<Expandable title="Cannot edit order after payment capture">

The Edit order button is missing once payment status changes to Paid.

**Problem**  
You need to add an item but the interface prevents changes.

**Cause**  
Shopify locks editing after the payment is captured to protect financial records.

**Fix**  
1. Issue a partial refund for the original amount.  
2. Create a new draft order with the corrected items.  
3. Send the updated invoice link to the customer for repayment.

</Expandable>

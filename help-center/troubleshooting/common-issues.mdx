## Common Issues

Use the sections below to identify symptoms, understand root causes, and apply targeted fixes for Zendesk Resolution Platform.

<Expandable title="AI agent fails to resolve complex tickets" default-open="false">
Problem: The AI agent returns the error message `Agent unable to determine resolution path for ticket #45231`.

Cause: The agent lacks access to updated knowledge base articles or required custom fields that define resolution criteria.

Fix: Update the agent's training data and verify field permissions.

1. Navigate to AI agents settings.
2. Select the affected agent and click Retrain.
3. Add the missing knowledge base articles.
4. Ensure the ticket fields `resolution_category` and `priority_level` are visible to the agent role.

Test the ticket again after saving changes.
</Expandable>

<Expandable title="Ticket triggers route inquiries to the wrong queue" default-open="false">
Problem: Tickets matching your automation rules land in the general queue instead of the specialized support queue.

Cause: A recent change to trigger conditions conflicts with an existing automation that runs first.

Fix: Reorder triggers and refine the condition logic.

1. Go to Admin Center then Triggers.
2. Locate the trigger named `Route to Tier 2`.
3. Move it above any broader catch-all triggers.
4. Update the condition to include `channel equals email` AND `tags contains enterprise`.

Save and retest with a sample ticket.
</Expandable>

<Expandable title="Integration sync fails with external CRM" default-open="false">
Problem: The sync status shows `Sync error: 409 Conflict on contact record update`.

Cause: Duplicate contact records exist in the connected CRM due to mismatched email normalization rules.

Fix: Align deduplication settings and force a manual resync.

1. Open Marketplace integrations and select your CRM connector.
2. Choose Settings then Deduplication rules.
3. Enable Normalize email domains.
4. Click Resync all contacts.

Monitor the sync log for successful completion.
</Expandable>

<Expandable title="Analytics dashboard shows mismatched ticket counts" default-open="false">
Problem: The resolution analytics report displays ticket totals that differ by 12 percent from the live ticket view.

Cause: Cached data from a recent platform update has not refreshed for the selected date range.

Fix: Clear the analytics cache and adjust the reporting interval.

1. Visit Reporting and analytics.
2. Select the affected dashboard.
3. Click the three-dot menu then choose Clear cache.
4. Change the date range to exclude today, then refresh.

The numbers should align within a few minutes.
</Expandable>

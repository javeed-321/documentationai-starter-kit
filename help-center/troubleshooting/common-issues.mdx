## Checkout and payment issues

<Expandable title="Payment declined at checkout" default-open="false">
Problem: Customers see the message "Your payment couldn't be processed. Please try again or use a different payment method." during checkout.

Cause: The payment gateway rejects the transaction due to mismatched billing details or insufficient funds on the customer's card.

Fix: Ask the customer to double-check their billing address matches the card issuer records. If the error persists, switch the payment method in Shopify admin under Settings > Payments and test with a different provider such as Shopify Payments.

</Expandable>

<Expandable title="Checkout page fails to load" default-open="false">
Problem: The checkout page shows a blank screen or spinner that never completes.

Cause: A required script from an installed sales channel or app is blocked by the browser.

Fix: In Shopify admin, go to Settings > Checkout and remove any custom scripts under Additional scripts. Save changes, then clear your browser cache and test the checkout again.

</Expandable>

## Inventory and order sync errors

<Expandable title="Inventory not updating after sale" default-open="false">
Problem: Stock levels remain the same even though an order was placed and paid for.

Cause: Automatic inventory tracking is disabled for the product variant.

Fix: Open the product in Shopify admin, select the variant, and enable Track quantity. Save, then manually adjust the inventory count under Inventory to sync the correct number.

</Expandable>

<Expandable title="Order fails to sync to fulfillment service" default-open="false">
Problem: New orders show the error "Unable to sync order to fulfillment service. Error code: 422".

Cause: The fulfillment app lacks permission to access order data.

Fix: Go to Settings > Apps and sales channels, locate your fulfillment app, and click Manage permissions. Grant full access to orders and inventory, then reinstall the app if the error continues.

</Expandable>

## Theme and customization bugs

<Expandable title="Custom CSS not appearing on storefront" default-open="false">
Problem: Changes made in the theme editor do not show on the live site.

Cause: The theme is loading a cached version of the stylesheet.

Fix: In the theme editor, click the three-dot menu and select Publish. Then append `?v=2` to the end of your store URL to force a cache refresh.

</Expandable>

<Expandable title="Section settings disappear after save" default-open="false">
Problem: Added sections vanish from the page layout after clicking Save.

Cause: The section uses an unsupported block type from a removed app.

Fix: Open the theme code editor, locate the section file under Sections, and remove any references to blocks that start with `app--`. Save and reload the theme editor.

</Expandable>

## App and integration issues

<Expandable title="App fails to connect to store" default-open="false">
Problem: The app installation screen shows "App could not be installed. API access request denied."

Cause: The app requests scopes that conflict with your current plan limits.

Fix: Upgrade to a plan that supports the required API scopes, then retry the installation from the Shopify App Store.

</Expandable>

<Expandable title="Data not syncing from connected sales channel" default-open="false">
Problem: Products added in a marketplace channel do not appear in Shopify admin.

Cause: The channel connection uses outdated OAuth tokens.

Fix: Disconnect the channel under Settings > Sales channels, then reconnect it and approve the new permission request when prompted.

</Expandable>

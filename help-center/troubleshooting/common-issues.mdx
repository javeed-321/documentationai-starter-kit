## Quick Fixes for Stuck Moments

We know how frustrating it feels when something breaks right before a sale. Each section below shows the exact symptom you see, why it happens, and the fastest way to get moving again.

<Expandable title="Payment declined at checkout" default-open="false">
Problem: Customers see the message `Payment declined: Your card was declined by the issuer.`

Cause: The payment gateway rejects the card because of mismatched billing details or temporary holds from the bank.

Fix: Ask the customer to re-enter the card with the exact billing address on file. If the error repeats, switch the order to manual capture in the order details screen and contact the bank directly with the authorization code shown in the transaction log.
</Expandable>

<Expandable title="Inventory not syncing across sales channels" default-open="false">
Problem: Stock levels show available in one channel but sold out in another, with the message `Sync failed: Inventory update rejected.`

Cause: A third-party warehouse app is overwriting Shopify's native stock count before the sync job finishes.

Fix: Pause the warehouse app in the Apps section, then run a manual inventory recount from the product page. Once counts match, re-enable the app and set its sync interval to every 15 minutes instead of real time.
</Expandable>

<Expandable title="Theme images appear broken or misaligned" default-open="false">
Problem: Product photos load as blank squares or overlap text, and the browser console shows `Failed to load resource: net::ERR_BLOCKED_BY_CLIENT`.

Cause: The theme's image compression setting conflicts with a browser extension or content blocker.

Fix: In the theme editor, open the product template, turn off automatic image optimization, save, and hard-refresh the storefront. If the issue continues, duplicate the theme, remove any custom liquid code that resizes images, and publish the copy.
</Expandable>

<Expandable title="App fails to install with permission error" default-open="false">
Problem: The install button shows `App could not be installed. Missing write_products scope.`

Cause: The app requests more access than your current staff account permissions allow.

Fix: Ask the store owner to grant you full permissions in Settings > Users and permissions. Then retry the install from the Shopify App Store page. If the error persists, contact the app developer with the exact scope name listed in the error.
</Expandable>

## Common Issues

Use the expanders below to match your symptom with the exact cause and fix. Each section includes the error message or behavior you see in Zendesk Help Center.

<Expandable title="Articles do not appear in search results" default-open="false">

**Problem**  
Your published articles return no matches when agents or end users search for keywords that exist in the title or body.

**Cause**  
The article is not indexed because its visibility setting is restricted to a group that the search user does not belong to, or the search index has not refreshed after the last publish.

**Fix**  
1. Open the article in edit mode.  
2. Check the visibility dropdown and set it to "Everyone" or a group the searcher belongs to.  
3. Click Publish, then run this command in your browser console while on the Help Center home page:  
   `document.querySelector('.search-input').value = 'your-keyword'; document.querySelector('.search-form').submit();`  
4. Wait two minutes and search again.

</Expandable>

<Expandable title="Theme changes do not appear or CSS is broken" default-open="false">

**Problem**  
After uploading a new theme or editing custom CSS, the Help Center still shows the old layout or displays raw CSS in the browser.

**Cause**  
The theme was not activated for the current brand, or a syntax error in the CSS file prevents the stylesheet from loading.

**Fix**  
1. Go to Guide admin > Customize design > Themes.  
2. Select your brand and click the three-dot menu next to the theme, then choose "Publish".  
3. Open the CSS file and look for unclosed braces or missing semicolons.  
4. Replace the faulty section with this minimal reset:  
   ```css
   .article-body { font-family: inherit; line-height: 1.5; }
   ```  
5. Save and publish again.

</Expandable>

<Expandable title="Permission or SSO login errors" default-open="false">

**Problem**  
Users see the message "You do not have permission to view this page" or are redirected to an SSO error page after clicking a Help Center link.

**Cause**  
The SSO configuration in Zendesk does not include the Help Center as an allowed redirect URI, or the user role lacks the "View Help Center" permission.

**Fix**  
1. In Zendesk Admin Center, go to Settings > Account > Security > Single sign-on.  
2. Edit the SSO configuration and add `https://your-subdomain.zendesk.com/hc` to the Allowed redirect URLs list.  
3. Save, then test with an incognito window.  
4. If the error persists, open Guide > Settings > Permissions and grant the role "Help Center access: View articles".

</Expandable>

<Expandable title="Web Widget does not load or shows blank" default-open="false">

**Problem**  
The web widget appears as a blank box or fails to load with the console error `zendeskWebWidget is not defined`.

**Cause**  
The widget snippet is placed before the required Zendesk script, or the Help Center domain is not added to the widget's allowed origins.

**Fix**  
1. Edit the document head and move the widget code block to the very end of the `<body>`.  
2. In Admin Center, go to Channels > Widget > Settings > Security.  
3. Add your Help Center URL under Allowed domains: `https://your-subdomain.zendesk.com`.  
4. Save and hard-refresh the page.

</Expandable>

## Overview

Discord Nitro enhances your experience by unlocking custom emojis, bigger file uploads, and server boosts. If you feel limited by the free plan, Nitro removes those barriers so you can express yourself and support communities more fully. This guide walks you through the main benefits, tier options, and how boosting works.

## Key Features

Nitro adds practical tools that make chatting and sharing easier.

## Subscription Tiers

Choose the plan that matches how you use Discord.

<Tabs>
  <Tab title="Nitro Basic" icon="star">

## Boosting Servers

Server boosts improve a community's features. Each boost you apply helps unlock levels that add perks such as more emoji slots and better voice channels.

<Expandable title="How to apply a boost" default-open="false">
  Open the server settings, select Server Boost, and choose how many boosts to add. You can move boosts between servers at any time.
</Expandable>

<Callout kind="tip">
  Boosts renew monthly with your subscription. Canceling Nitro removes the boosts after the current period ends.
</Callout>

## Best Practices

- Start with Nitro Basic if you only need emojis and uploads.
- Use boosts on smaller servers where they make the biggest difference.
- Check the boost status in server settings before applying so you know the current level.

If a feature does not appear after subscribing, restart the app or check your account settings on the billing page.

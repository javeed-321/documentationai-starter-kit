## Overview

Event types let you control exactly how meetings appear on your booking page. You set the length, the meeting location, and any questions you want answered before the event is confirmed. Clear event types reduce back-and-forth and help invitees book the right slot the first time.

## Single versus group events

Choose the event style that matches your workflow.

<Tabs>
  <Tab title="Single event" icon="user">
    One host meets one invitee. Ideal for 1:1 calls, interviews, or consultations.

    - Set a fixed duration such as 30 or 60 minutes.
    - Pick one location: video link, phone, or in-person address.
    - Limit availability to specific days or hours.

  </Tab>
  <Tab title="Group event" icon="users">
    Multiple invitees join the same session. Useful for webinars, office hours, or workshops.

    - Define a maximum number of attendees.
    - Choose collective or round-robin scheduling.
    - Share one booking link that fills seats until the limit is reached.

  </Tab>
</Tabs>

## Adding custom questions

Ask for details before the meeting starts.

<Callout kind="tip">
  Keep questions short. Invitees are more likely to finish the booking when the form feels quick.
</Callout>

Use the questions builder to add fields such as:

- Company name or role
- Project description
- Preferred time zone
- File upload for agendas or resumes

Answers appear in the calendar invite and confirmation email.

## Setting buffer times

Buffer times prevent back-to-back meetings from running into each other.

<Steps>
  <Step title="Open the event type">
    Select the event type and go to the Availability tab.

  </Step>
  <Step title="Add buffers">
    Enter the number of minutes you need before or after each meeting.

  </Step>
  <Step title="Save and test">
    Publish the change, then open your booking page in a private window to confirm the gaps appear.

  </Step>
</Steps>

## Examples

Here is a common setup for a 30-minute sales call:

```markdown
Event name: Discovery call
Duration: 30 minutes
Location: Calendly video
Buffer: 15 minutes before, 15 minutes after
Questions: Company size, current tools in use
```

## Best practices

<ExpandableGroup>
  <Expandable title="Name events clearly" default-open="true">
    Use plain language that invitees recognize. "30-minute product demo" works better than internal codes.

  </Expandable>
  <Expandable title="Limit required fields">
    Ask only what you truly need. Extra questions increase drop-off rates.

  </Expandable>
  <Expandable title="Review buffers monthly">
    Adjust buffers when your meeting load changes so you stay on schedule without long gaps.

  </Expandable>
</ExpandableGroup>

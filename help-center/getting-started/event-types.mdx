## Set up your first event type

You need an event type so people can book time with you without email back-and-forth. This page shows you how to create single or group events, add buffer time, and ask custom questions.

## Choose single or group events

Use this table to decide which type fits your needs.

| Event type | Best for | Max invitees |
|------------|----------|--------------|
| Single | One-on-one meetings | 1 |
| Group | Team sessions or webinars | Up to 50 |

## Create an event type

Follow these steps to build your event.

<Steps>
<Step title="Open the Event Types page">
  Sign in to Calendly and click Event Types in the left menu.

</Step>
<Step title="Start a new event">
  Click the New Event Type button and choose Single Event or Group Event.

</Step>
<Step title="Set the basics">
  Enter a name, description, and duration. Pick your calendar and available times.

</Step>
<Step title="Add buffers and limits">
  Turn on buffer time before or after the event. Set a minimum notice period and daily booking limit.

</Step>
<Step title="Add custom questions">
  Click the Questions tab. Add any fields you need, such as company name or project details.

</Step>
</Steps>

<Callout kind="tip">
  Test your event type by copying the link and opening it in an incognito window.
</Callout>

## Common questions

<Expandable title="Can I change the duration later?">
  Yes. Open the event type, edit the duration field, and save. Existing bookings keep their original length.

</Expandable>

<Expandable title="How do buffer times work?">
  Buffers block time on your calendar so you have a break between meetings. They do not appear to invitees.

</Expandable>

## Overview

Discord servers give you a dedicated space to chat, play, and hang out with friends or communities. You can create one in seconds, then shape it with roles, permissions, and channels that match how you like to connect.

If you feel stuck on where to begin, start with the basics below. Each step builds on the last so you can move at your own pace.

## Setting Up Your Server

Follow these steps to create a server and invite your first members.

<Steps>
  <Step title="Create the server">
    Open Discord, click the plus icon on the left sidebar, then choose Create My Own. Pick a template or start from scratch and give your server a name.

  </Step>
  <Step title="Invite friends">
    Click the Invite People button next to your server name. Copy the link and share it, or send direct invites to friends already on Discord.

  </Step>
  <Step title="Add a few channels">
    Right-click the server name and select Create Channel. Start with one text channel for general chat and one voice channel for talking while gaming.

  </Step>
</Steps>

<Callout kind="tip">
  Keep your first server small. You can always add more channels and roles later once you see how people use the space.
</Callout>

## Roles and Permissions

Roles let you decide who can do what. Start with simple roles like Member and Moderator.

<Tabs>
  <Tab title="Member" icon="users">
    Members can chat, join voice channels, and react to messages. This is the default role for most people.

  </Tab>
  <Tab title="Moderator" icon="shield">
    Moderators can delete messages and mute troublemakers. Give this role only to people you trust.

  </Tab>
</Tabs>

<Expandable title="How do I change permissions later?" default-open="false">
  Right-click any role in Server Settings, then adjust the toggles. Changes apply right away, so test with a small group first.

</Expandable>

## Best Practices

- Name channels clearly so new members know where to go.
- Review role permissions every few weeks as your group grows.
- Pin important messages in each channel so rules stay visible.
- Ask members what they need before adding too many extra channels.

If anything feels off, you can always delete a channel or role and start fresh. For more help, reach out to @discord_support.

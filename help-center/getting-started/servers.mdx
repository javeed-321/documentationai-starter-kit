## Creating Your First Server

You need a dedicated space for your group but do not know how to begin. This page shows you exactly how to create a server, assign roles, and set up channels.

<Steps>
<Step title="Create the server">
  Open Discord and click the plus icon on the left sidebar.

  Select "Create My Own" and choose whether the server is for friends or a club.

  Enter a server name and upload an icon if you want one.

  Click "Create" to finish.

</Step>
<Step title="Invite your first members">
  Click the server name at the top and choose "Invite People".

  Copy the link or select specific friends to send it to.

</Step>
</Steps>

## Setting Up Roles and Permissions

Roles control what members can do. Start with the default @everyone role, then add more.

| Role name   | Typical permissions                  | Use case                  |
|-------------|--------------------------------------|---------------------------|
| Moderator   | Manage messages, kick members        | Help keep order           |
| Member      | Send messages, use voice chat        | Everyday participants     |
| Admin       | All permissions except owner-only    | Trusted helpers           |

<Callout kind="tip">
  Keep the number of roles small at first. Too many roles make management harder.
</Callout>

## Adding Channels

Channels organize conversations. Create text channels for chat and voice channels for talking.

<Steps>
<Step title="Add a text channel">
  Right-click the server name and select "Create Channel".

  Choose "Text" and give it a clear name like "general" or "announcements".

  Set permissions so only the right roles can post.

</Step>
<Step title="Add a voice channel">
  Repeat the same steps but choose "Voice" instead.

  Name it after the activity, such as "Game Night".

</Step>
</Steps>

## Common Questions

<Expandable title="Can I change the server icon later?">
  Yes. Click the server name, choose "Server Settings", then click the current icon to upload a new one.
</Expandable>

<Expandable title="How do I delete a channel?">
  Right-click the channel name and select "Delete Channel". Confirm the action.
</Expandable>

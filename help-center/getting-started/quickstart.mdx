## Overview

Discord makes it easy to connect with friends through text, voice, and video. Follow these steps to get started quickly without frustration.

## Download the App

Pick the version that matches your device.

<Tabs>
  <Tab title="Windows" icon="monitor">
    Go to the Discord website and click the download button for the desktop app.
  </Tab>
  <Tab title="macOS" icon="apple">
    Visit the site and select the macOS installer to get the desktop client.
  </Tab>
  <Tab title="Mobile" icon="smartphone">
    Open your app store and search for Discord to install on iOS or Android.
  </Tab>
</Tabs>

## Create Your Account

Set up your profile in a few minutes.

<Steps>
  <Step title="Sign up">
    Enter your email address and create a username.

    Choose a strong password to keep your account secure.
  </Step>
  <Step title="Verify email">
    Check your inbox for the confirmation link and click it.

    This step unlocks full access to servers and chats.
  </Step>
</Steps>

<Callout kind="tip">
  Use the same email you check often so you never miss verification messages.
</Callout>

## Join Your First Server

Find a community and start talking.

<Card title="Server Directory" icon="users" href="#">
  Browse public servers by topic to find one that matches your interests.
</Card>

<Expandable title="What if the invite link fails?" default-open="false">
  Double-check the link for typos. Ask the server owner for a fresh invite if needed.
</Expandable>

## Best Practices

- Keep your username simple so others can find you.
- Enable two-factor authentication right after setup.
- Start with smaller servers to learn the layout before joining large ones.

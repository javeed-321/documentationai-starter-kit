## Overview

Importing your audience into Mailchimp lets you start sending personalized campaigns right away. The process is straightforward, but taking time to organize contacts and respect privacy rules keeps your list healthy and compliant.

You can bring in contacts from a CSV file, then group them into segments for targeted sends. Always confirm you have permission before uploading any addresses.

## Importing Contacts via CSV

Prepare your file with clear column headers such as Email Address, First Name, and Last Name. Mailchimp reads the first row as labels, so consistent naming helps the import run smoothly.

1. Go to the Audience section and select Import Contacts.
2. Upload your CSV file or paste data directly.
3. Map each column to the matching Mailchimp field.
4. Review the preview, then start the import.

<Callout kind="tip">
Double-check that every contact gave you permission to email them. This step protects your sender reputation.
</Callout>

## Organizing Segments

Segments let you send the right message to the right people without creating separate lists.

<Tabs>
  <Tab title="Basic segment" icon="filter">
    Choose conditions such as signup date or engagement level. Save the segment so you can reuse it later.
  </Tab>
  <Tab title="Advanced segment" icon="sliders">
    Combine multiple rules, for example subscribers in a certain city who opened your last campaign.
  </Tab>
</Tabs>

## Maintaining GDPR Compliance

If any contacts are in Europe, GDPR rules apply. Mailchimp provides tools to record consent and handle requests.

<Expandable title="What to do before import" default-open="false">
  Add a consent field to your CSV and only include contacts who opted in. Keep records of when and how each person gave permission.
</Expandable>

<Expandable title="Handling data requests" default-open="false">
  Use the contact profile tools to export or delete individual records when someone asks.
</Expandable>

## Example CSV Structure

```csv
Email Address,First Name,Last Name,Signup Date,Consent
jane@example.com,Jane,Doe,2024-01-15,yes
```

## Best Practices

- Clean your list before import by removing duplicates and bounced addresses.
- Start with a small test file to confirm field mapping.
- Review Mailchimp's compliance checklist after every import.
- Revisit segments quarterly to keep them relevant.

These steps help you build a strong, respectful audience that engages with your campaigns.

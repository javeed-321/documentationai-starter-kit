## Overview

Getting files into Dropbox should feel simple. Whether you are starting fresh or moving an existing project, the platform supports quick uploads and clear organization so you never lose track of your work.

## Drag-and-Drop Uploads

The fastest way to add content is to drag files or folders straight from your computer onto the Dropbox web or desktop interface.

1. Open Dropbox in your browser or desktop app.
2. Locate the destination folder.
3. Drag your items over the upload area and release.

<Callout kind="tip">
If a file fails to upload, check your internet connection and file size limits first.
</Callout>

## Organizing with Folders

A logical folder structure keeps projects easy to find. Create top-level folders for clients or departments, then nest subfolders as needed.

<Tabs>
  <Tab title="Web" icon="monitor">
    Click the folder icon, enter a name, and press enter. Drag existing items into the new folder.
  </Tab>
  <Tab title="Desktop" icon="terminal">
    Right-click inside any synced folder, choose New Folder, then move files using your file manager.
  </Tab>
</Tabs>

## Using Version History

Dropbox automatically saves previous versions of files so you can restore an earlier copy if something goes wrong.

<Expandable title="How to restore a previous version" default-open="false">
  Right-click the file, select Version history, then choose the version you need and click Restore.
</Expandable>

## Overview

Zendesk voice capabilities let you handle inbound and outbound calls inside the same workspace you use for chat, email, and messaging. AI agents answer routine questions, route complex issues to live agents, and transcribe every conversation for quality reviews. Workforce management tools balance agent schedules against real-time demand so customers never wait long.

## Call Flows

Configure IVR menus and intelligent routing directly in the admin interface. Choose from simple menu trees or dynamic flows that adapt based on customer history and current queue length.

<Tabs>
  <Tab title="Basic IVR" icon="phone">
    Present callers with numbered options and transfer them to the right queue.

    - Press 1 for billing
    - Press 2 for technical support
    - Press 0 to speak with an agent

  </Tab>
  <Tab title="AI Routing" icon="bot">
    Let the AI agent greet callers, collect details, and decide the best path without menus.

    The agent checks the customer's recent tickets and offers a callback if wait times exceed two minutes.

  </Tab>
</Tabs>

## AI Transcription

Every call is transcribed automatically. Transcripts appear in the ticket timeline so agents can review context before follow-up work.

<Callout kind="info">
  Enable transcription in one click under Voice settings. Transcripts support 50+ languages and are searchable from the ticket list.
</Callout>

## Example Configuration

Use the following snippet to define a sample call flow that combines AI greeting with live-agent escalation.

````jsx
<CodeGroup tabs="JSON,YAML">
```json
{
  "flow": "voice-ai-greeting",
  "steps": [
    { "type": "ai-greet", "language": "en" },
    { "type": "check-wait", "threshold": 120 },
    { "type": "transfer", "queue": "support-tier-2" }
  ]
}
```
```yaml
flow: voice-ai-greeting
steps:
  - type: ai-greet
    language: en
  - type: check-wait
    threshold: 120
  - type: transfer
    queue: support-tier-2
```
</CodeGroup>
````

## Best Practices

Follow these guidelines to keep voice support fast and consistent.

<ExpandableGroup>
  <Expandable title="Keep menus short" default-open="false">
    Limit IVR choices to three options. Longer menus increase hang-ups and frustrate callers who already waited in queue.
  </Expandable>
  <Expandable title="Review transcripts weekly" default-open="false">
    Listen to a sample of calls each week. Use the quality assurance tools to tag coaching moments and share clips with the team.
  </Expandable>
  <Expandable title="Sync schedules with real demand" default-open="false">
    Update forecasts after every campaign or product launch. Adjust shifts the same day when unexpected spikes appear.
  </Expandable>
</ExpandableGroup>

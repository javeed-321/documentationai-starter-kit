## Overview

Picking the right Calendly plan helps you avoid extra costs while getting the features you need. Start with the free plan if you schedule a few meetings each week. Move up when you need more calendars, reminders, or team controls.

## Admin controls

Enterprise teams need more oversight. You can set permissions, enforce security rules, and review activity logs from one dashboard.

<Expandable title="What admin controls include" default-open="false">
  - Require single sign-on for every user
  - Set custom approval workflows for new event types
  - Export usage reports for compliance reviews

</Expandable>

## Best practices

- Start on the lowest plan that covers your calendar count and reminder needs.
- Review seat usage monthly so you do not pay for empty seats.
- Contact sales when your team reaches five or more active users.

<Callout kind="tip">
  Test the free plan first. You can upgrade at any time without losing your existing booking links.
</Callout>

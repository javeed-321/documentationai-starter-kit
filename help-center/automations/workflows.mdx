You want to automate customer journeys without manual follow-ups. This page shows how to build them in Mailchimp using the journey builder, trigger conditions, and A/B testing.

## Journey Builder Basics

The journey builder lets you map out automated paths that react to customer actions.

## Create Your First Automation

<Steps>
  <Step title="Open the builder">
    Go to Automations and click Create Journey.
  </Step>
  <Step title="Choose a starting point">
    Select a template such as Welcome or Abandoned Cart.
  </Step>
  <Step title="Add actions">
    Drag in email sends, delays, or splits to shape the path.
  </Step>
</Steps>

## Set Trigger Conditions

Triggers start the journey when specific events occur.

| Trigger | When it fires |
| ------- | ------------- |
| New signup | A contact joins your list |
| Cart abandoned | A visitor leaves items in checkout |
| No purchase | A contact has not bought in 30 days |

<Callout kind="tip">
  Test each trigger with a small audience before going live.
</Callout>

## Run A/B Tests

Compare two versions of an email inside the same journey.

<Steps>
  <Step title="Add a split">
    Insert an A/B split block after your trigger.
  </Step>
  <Step title="Define the test">
    Choose subject line or content as the variable.
  </Step>
  <Step title="Set the winner rule">
    Pick the version with the highest open rate after 24 hours.
  </Step>
</Steps>

## Common Questions

<Expandable title="Can I edit a journey after it starts?">
  Yes. Pause the automation, make changes, then resume it.
</Expandable>

<Expandable title="How many journeys can I run at once?">
  Your plan sets the limit. Check your account dashboard for the current number.
</Expandable>

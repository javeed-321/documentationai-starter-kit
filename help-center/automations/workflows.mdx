## Overview

Marketing automations help you reach the right people at the right time without manual work. You set up a journey once, and Mailchimp handles the rest based on how contacts behave. This guide walks you through the main tools so you can launch your first automated series today.

## Journey Builder

The journey builder is the canvas where you map every step. Start by choosing a starting point, then add actions like sending an email or waiting a set number of days.

<Steps>
  <Step title="Open the builder">
    From the Automations menu, select Create journey and pick a template or start blank.
  </Step>
  <Step title="Add your first action">
    Drag an email block onto the canvas and choose the message you want to send.
  </Step>
  <Step title="Connect the steps">
    Draw lines between blocks to set the order. Add splits if you need different paths.
  </Step>
</Steps>

## Trigger Conditions

Triggers decide when a contact enters the journey. Use simple rules so only the right people start the flow.

<Callout kind="tip">
  Keep triggers narrow at first. You can always widen them later if too few contacts enter.
</Callout>

<Tabs>
  <Tab title="Welcome series" icon="mail">
    Trigger when a new contact is added to your audience list.
  </Tab>
  <Tab title="Abandoned cart" icon="shopping-cart">
    Trigger when a contact adds items but does not complete checkout within 24 hours.
  </Tab>
  <Tab title="Re-engagement" icon="users">
    Trigger when a contact has not opened an email in the last 90 days.
  </Tab>
</Tabs>

## A/B Testing

Test two versions of an email inside the same journey to see which performs better.

<Expandable title="How to set up an A/B test" default-open="false">
  Add an A/B split block after the trigger. Choose the element to test (subject line, from name, or content). Mailchimp automatically sends the winner to the rest of your audience after the test period ends.
</Expandable>

## Best Practices

- Write one clear goal for each journey before you build it.
- Use short wait times between messages so contacts remember why they received the first email.
- Review performance after the first week and remove any step that gets low clicks.

<Callout kind="info">
  If a journey sends to zero contacts, double-check the trigger conditions first.
</Callout>

## Prerequisites

<Callout kind="info">
You need a ShopifyMax store and an admin account with permission to create private apps.
</Callout>

## Install a private app

<Steps>
<Step title="Create the app">
Log in to your ShopifyMax admin and navigate to Apps. Click Develop apps, then Create an app. Name it Quickstart App and generate API credentials.
</Step>
<Step title="Configure scopes">
Select the scopes `read_products` and `write_products`. Save the changes and install the app on your development store.
</Step>
<Step title="Copy credentials">
Copy the Admin API access token. Store it securely as `YOUR_ACCESS_TOKEN`.
</Step>
</Steps>

## Make your first request

Use the following GraphQL query to fetch the first five products.

<CodeGroup tabs="cURL,Node.js">
````bash
curl -X POST \
  https://your-store.example.com/admin/api/2024-01/graphql.json \
  -H 'Content-Type: application/json' \
  -H 'X-Shopify-Access-Token: YOUR_ACCESS_TOKEN' \
  -d '{"query":"{ products(first:5) { edges { node { id title } } } }"}'
````
````javascript
const response = await fetch(
  "https://your-store.example.com/admin/api/2024-01/graphql.json",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-Shopify-Access-Token": "YOUR_ACCESS_TOKEN",
    },
    body: JSON.stringify({
      query: "{ products(first:5) { edges { node { id title } } } }",
    }),
  }
);
const data = await response.json();
console.log(data);
````
</CodeGroup>

## Handle rate limits

ShopifyMax returns the header `X-Shopify-Shop-Api-Call-Limit`. When the value approaches the bucket size, pause requests until the limit resets.

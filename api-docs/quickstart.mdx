## Prerequisites

<Callout kind="info">
Obtain a secret key from your account dashboard before making requests. Replace `YOUR_API_KEY` in examples with that value.
</Callout>

## Server-side integration

<Steps>
<Step title="Prepare the request">
Send an authenticated POST request to the charges endpoint. Include an amount, currency, and source token.
</Step>
<Step title="Add an idempotency key">
Pass the `Idempotency-Key` header to ensure the operation executes only once even if the request is retried.
</Step>
</Steps>

<CodeGroup tabs="cURL">
```bash
curl https://api.example.com/v1/charges \
  -u YOUR_API_KEY: \
  -H "Idempotency-Key: key_123" \
  -d amount=2000 \
  -d currency=usd \
  -d source=tok_visa
```
</CodeGroup>

## Client-side tokenization

Collect card details on the client and exchange them for a single-use token before sending the token to your server.

<CodeGroup tabs="cURL">
```bash
curl https://api.example.com/v1/tokens \
  -u YOUR_API_KEY: \
  -d "card[number]"=4242424242424242 \
  -d "card[exp_month]"=12 \
  -d "card[exp_year]"=2025 \
  -d "card[cvc]"=123
```
</CodeGroup>

## Idempotency keys

Use the same key for retries of the same logical operation. Keys remain valid for 24 hours.

## Prerequisites

<Callout kind="info">
Obtain an API key from the dashboard before making requests. Use test mode keys for initial calls.
</Callout>

You need an account and a secret key. Requests go to the payments endpoint.

## Setup

<Steps>
  <Step title="Obtain credentials">
    Log in to retrieve your secret key from the dashboard.
  </Step>
  <Step title="Prepare request">
    Set the authorization header with your key.
  </Step>
</Steps>

## Create a charge

Use the following examples to create a PaymentIntent.

<CodeGroup tabs="cURL,Node">
```bash
curl https://api.example.com/v1/payment_intents \
  -u sk_test_YOUR_API_KEY: \
  -d amount=2000 \
  -d currency=usd \
  -d "payment_method_types[]"=card
```

```js
const response = await fetch("https://api.example.com/v1/payment_intents", {
  method: "POST",
  headers: {
    Authorization: "Bearer sk_test_YOUR_API_KEY",
    "Content-Type": "application/x-www-form-urlencoded",
  },
  body: new URLSearchParams({
    amount: "2000",
    currency: "usd",
    "payment_method_types[]": "card",
  }),
});
```
</CodeGroup>

## Prerequisites

<Callout kind="info">

Obtain a set of API keys from your Stripe account dashboard before making requests. Use the secret key only on the server.

</Callout>

## Set up your environment

<Steps>
  <Step title="Install a client library">

    Choose a language and install the official library.

    ```bash
    npm install stripe
    ```

  </Step>
  <Step title="Configure your key">

    Store the secret key in an environment variable.

    ```bash
    export STRIPE_SECRET_KEY=sk_test_YOUR_KEY
    ```

  </Step>
</Steps>

## Create a charge

Use the following examples to create a test charge.

<CodeGroup tabs="cURL,Node.js">
```bash
curl https://api.stripe.com/v1/charges \
  -u $STRIPE_SECRET_KEY: \
  -d amount=2000 \
  -d currency=usd \
  -d source=tok_visa \
  -d description="Test charge"
```
```js
const stripe = require("stripe")(process.env.STRIPE_SECRET_KEY);

const charge = await stripe.charges.create({
  amount: 2000,
  currency: "usd",
  source: "tok_visa",
  description: "Test charge",
});
```
</CodeGroup>

## Use test data

All requests above use test card tokens such as `tok_visa`. No real funds move.

## Handle errors

Inspect the returned error object for details.

```js
try {
  const charge = await stripe.charges.create({...});
} catch (err) {
  console.error(err.type, err.message);
}
```

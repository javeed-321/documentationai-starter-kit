## Overview

ShopifyMax uses OAuth 2.0 to secure API access for both public and private apps. Public apps request merchant authorization through permission flows, while private apps authenticate directly with API credentials. All requests must include a valid access token.

## Authentication Methods

<Tabs>
  <Tab title="Public Apps" icon="users">
    Public apps use the merchant permission flow. Merchants grant access via an authorization URL that includes requested scopes.

    After approval, ShopifyMax returns an authorization code. Exchange the code for an access token using the token endpoint.
  </Tab>
  <Tab title="Private Apps" icon="lock">
    Private apps authenticate with an API key and secret. Generate these in the ShopifyMax admin and use them to obtain a permanent access token.
  </Tab>
</Tabs>

## Implementation

<CodeGroup tabs="JavaScript,Python,cURL">
```javascript
const response = await fetch('https://api.example.com/oauth/token', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    client_id: 'YOUR_API_KEY',
    client_secret: 'YOUR_API_SECRET',
    code: 'AUTH_CODE',
    grant_type: 'authorization_code',
  }),
});
const data = await response.json();
```

```python
import requests

response = requests.post(
    'https://api.example.com/oauth/token',
    json={
        'client_id': 'YOUR_API_KEY',
        'client_secret': 'YOUR_API_SECRET',
        'code': 'AUTH_CODE',
        'grant_type': 'authorization_code',
    },
)
data = response.json()
```

```bash
curl -X POST https://api.example.com/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": "YOUR_API_KEY",
    "client_secret": "YOUR_API_SECRET",
    "code": "AUTH_CODE",
    "grant_type": "authorization_code"
  }'
```
</CodeGroup>

## Request Parameters

<ParamField header="Authorization" param-type="string" required="true">
  Bearer token obtained from the OAuth flow. Format: `Bearer YOUR_ACCESS_TOKEN`.
</ParamField>

<ParamField query="client_id" param-type="string" required="true">
  Your public API key from the ShopifyMax app settings.
</ParamField>

<ParamField query="scope" param-type="string" required="true">
  Space-separated list of OAuth scopes such as `read_orders write_products`.
</ParamField>

## Environment Variables

Store credentials outside source code.

```bash
SHOPIFYMAX_API_KEY=YOUR_API_KEY
SHOPIFYMAX_API_SECRET=YOUR_API_SECRET
SHOPIFYMAX_ACCESS_TOKEN=YOUR_ACCESS_TOKEN
```

## Security Recommendations

<Callout kind="alert">
  Never expose API secrets or access tokens in client-side code. Rotate tokens regularly and revoke access immediately if a token is compromised. Always use HTTPS for all OAuth endpoints.
</Callout>

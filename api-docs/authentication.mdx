## Overview

Stripe authenticates every API request with credentials that identify your account and control access. Use secret keys for server-side calls, publishable keys for client-side requests, and signatures to verify webhook events. OAuth enables delegated access for Connect platforms.

## Authentication methods

<Tabs>
  <Tab title="Secret keys" icon="key">
    Send your secret key in the Authorization header for all server-to-server requests. Keep this value private and rotate it regularly.

    <ParamField header="Authorization" param-type="string" required="true">
      Bearer token containing your secret key.
    </ParamField>
  </Tab>
  <Tab title="Publishable keys" icon="globe">
    Use publishable keys in browser or mobile code to create tokens or confirm payments. These keys are safe to expose publicly.

    <ParamField header="Authorization" param-type="string" required="true">
      Bearer token containing your publishable key.
    </ParamField>
  </Tab>
  <Tab title="Webhook signatures" icon="shield">
    Verify that webhook payloads originate from Stripe by checking the signature header against your endpoint secret.

    <ParamField header="Stripe-Signature" param-type="string" required="true">
      HMAC signature generated with your webhook secret.
    </ParamField>
  </Tab>
  <Tab title="OAuth for Connect" icon="link">
    Request access tokens on behalf of connected accounts using the OAuth flow. Exchange the authorization code for an access token.

    <ParamField query="code" param-type="string" required="true">
      Temporary authorization code returned after the user approves access.
    </ParamField>
  </Tab>
</Tabs>

## Implementation examples

Store credentials in environment variables and load them at runtime.

```bash
STRIPE_SECRET_KEY=sk_test_YOUR_SECRET_KEY
STRIPE_PUBLISHABLE_KEY=pk_test_YOUR_PUBLISHABLE_KEY
STRIPE_WEBHOOK_SECRET=whsec_YOUR_WEBHOOK_SECRET
```

<CodeGroup tabs="cURL,Python,Node.js">
```bash
curl https://api.example.com/v1/charges \
  -u sk_test_YOUR_SECRET_KEY: \
  -d amount=2000 \
  -d currency=usd \
  -d source=tok_visa
```

```python
import stripe
import os

stripe.api_key = os.environ["STRIPE_SECRET_KEY"]

charge = stripe.Charge.create(
    amount=2000,
    currency="usd",
    source="tok_visa",
)
```

```javascript
const stripe = require("stripe")(process.env.STRIPE_SECRET_KEY);

const charge = await stripe.charges.create({
  amount: 2000,
  currency: "usd",
  source: "tok_visa",
});
```
</CodeGroup>

## Security recommendations

<Callout kind="alert">
Never commit secret keys to source control. Rotate keys immediately if they are exposed. Always verify webhook signatures before processing event data.
</Callout>

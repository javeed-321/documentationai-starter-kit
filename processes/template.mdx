## Purpose

This template standardizes how teams record recurring processes inside Notion. It covers template creation, database-backed project tracking, AI-assisted reporting, and cross-team handoffs. Use the template to keep every process page consistent and searchable.

## Steps

<Steps>
  <Step title="Create and customize the template">
    Duplicate the base page inside your workspace. Add or remove sections to match the workflow. Lock the page once the structure is approved so contributors cannot alter headings or required fields.

  </Step>
  <Step title="Set up project tracking with databases">
    Link a database view that stores tasks, owners, and due dates. Configure filters so each process page surfaces only its related items. Add rollup properties to surface status at the top of the page.

  </Step>
  <Step title="Configure AI-assisted reporting">
    Insert an AI summary block at the end of the page. Point the block at the linked database so it generates weekly status updates. Review the generated text before publishing to ensure accuracy.

  </Step>
  <Step title="Define cross-team handoff points">
    Add a handoff table that lists the receiving team, required artifacts, and acceptance criteria. Tag the responsible owner in each row so notifications fire when a step is marked complete.

  </Step>
</Steps>

## Owners

- Primary owner: Workflow Enablement
- Secondary owner: AI Platform team
- Reviewer: Process council representative

## Review Cadence

Update the template quarterly. The primary owner collects feedback during the last week of each quarter and publishes revisions on the first Monday of the following quarter.

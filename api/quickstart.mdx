## Prerequisites

<Callout kind="info">
Obtain an API key from your MetricsFlow dashboard at `https://dashboard.example.com`. Set the key as the `METRICSFLOW_API_KEY` environment variable before running any code.
</Callout>

## Install the client library

<Steps>
  <Step title="Install via npm" icon="download">
    Run the following command in your project directory:

    ```bash
    npm install @metricsflow/client
    ```
  </Step>
  <Step title="Install via pip" icon="download">
    For Python projects, use:

    ```bash
    pip install metricsflow-client
    ```
  </Step>
</Steps>

## Minimal working example

<CodeGroup tabs="JavaScript,Python">
```javascript
import { MetricsFlowClient } from '@metricsflow/client';

const client = new MetricsFlowClient({
  apiKey: process.env.METRICSFLOW_API_KEY,
});

async function runQuickstart() {
  // Ingest a batch of events
  await client.ingestEvents([
    { event_type: 'page_view', user_id: 'u123', timestamp: Date.now() },
  ]);

  // Run an aggregation query
  const result = await client.queryAggregation({
    metric: 'count',
    dimensions: ['event_type'],
    time_range: { start: 'now-1h', end: 'now' },
  });

  console.log(result);
}

runQuickstart();
```
```python
from metricsflow_client import MetricsFlowClient
import os

client = MetricsFlowClient(api_key=os.environ["METRICSFLOW_API_KEY"])

def run_quickstart():
    # Ingest a batch of events
    client.ingest_events([
        {"event_type": "page_view", "user_id": "u123", "timestamp": 1728000000000}
    ])

    # Run an aggregation query
    result = client.query_aggregation(
        metric="count",
        dimensions=["event_type"],
        time_range={"start": "now-1h", "end": "now"},
    )

    print(result)

run_quickstart()
```

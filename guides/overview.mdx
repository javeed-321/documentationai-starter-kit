## Overview

Notion handles non-English content with built-in support for diverse scripts and languages. You work in your preferred locale while teams collaborate across boundaries. Core features include language-aware blocks, locale-specific database filters, flexible import and export, and real-time mixed-language collaboration.

## Language-aware blocks

Blocks detect and render text correctly regardless of script direction or character set. You type naturally and Notion preserves formatting, line breaks, and alignment.

<Card title="Supported scripts" icon="globe" href="#examples">
  Covers Latin, CJK, Cyrillic, Arabic, Hebrew, and more without manual configuration.
</Card>

## Database filtering by locale

Filter and sort database entries by language tags or locale codes. Create views that surface only Japanese records or group Arabic content automatically.

<Tabs>
  <Tab title="Filter example" icon="filter">
    Use the filter menu to select `Locale equals ja-JP` and instantly see only Japanese pages.
  </Tab>
  <Tab title="Sort example" icon="arrow-up-down">
    Sort by `Language` field to keep English and French sections adjacent.
  </Tab>
</Tabs>

## Export and import options

Export pages or databases while retaining original language metadata. Import from CSV or other sources and map locale columns during the process.

<CodeGroup tabs="CSV import,Markdown export">
```csv
Page Title,Locale,Content
Welcome,en-US,Hello team
ようこそ,ja-JP,こんにちはチーム
```
```md
---
title: ようこそ
locale: ja-JP
---
こんにちはチーム
```
</CodeGroup>

## Collaboration in mixed-language workspaces

Multiple users edit the same page in different languages simultaneously. Comments and mentions stay readable across scripts.

## Best practices

- Set the page locale early so filters and exports behave predictably.
- Use consistent language tags across databases to avoid mismatched results.
- Review import mappings before confirming to preserve non-Latin characters.

Start with a new page and enable language-aware blocks to experience the difference immediately.

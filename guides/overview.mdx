## Overview

Vercel provides a unified platform for building, deploying, and scaling web applications. From the moment you connect a Git repository, automated pipelines handle builds and previews while Fluid Compute provisions resources on demand. AI Cloud tools add model access, safe execution environments, and agent capabilities. Security controls protect every deployment with DDoS mitigation, a web application firewall, and bot detection.

## CI/CD Pipelines and Previews

Every push triggers an instant build that produces a unique preview URL. Teams review changes in isolation before promotion to production.

<Callout kind="info">
  Preview URLs remain live until you delete the deployment or the branch is removed.
</Callout>

## Fluid Compute and Serverless Functions

Fluid Compute automatically scales serverless functions from zero to thousands of instances. You write standard JavaScript or TypeScript without managing servers or containers.

```javascript
export default function handler(req, res) {
  res.status(200).json({ message: "Hello from Vercel" });
}
```

## AI-Specific Tools and Sandboxing

Vercel AI Cloud supplies a single endpoint for multiple models, an isolated sandbox for code execution, and an agent that understands your project structure.

## Best Practices

<Expandable title="Optimize preview workflows" default-open="false">

Limit concurrent builds by configuring branch ignore rules in your project settings. This keeps preview costs predictable while maintaining fast feedback loops.

</Expandable>

<Expandable title="Secure AI endpoints" default-open="false">

Apply rate limits and origin checks on AI Gateway routes. Combine BotID with WAF rules to block automated abuse before it reaches your models.

</Expandable>

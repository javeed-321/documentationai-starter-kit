## Overview

Vercel provides a unified platform for building and deploying modern web applications. From the moment you connect a repository, automated pipelines handle builds, previews, and production releases. Fluid Compute dynamically allocates resources, while the global edge network delivers content with low latency. AI tooling extends these capabilities with model access and TypeScript utilities.

## CI/CD Pipelines

Instant pipelines trigger on every Git push. Previews appear automatically, and production updates follow successful checks.

<Callout kind="info">
  Enable branch protection rules to require preview approval before merging.
</Callout>

## Fluid Compute

Fluid Compute provisions the exact CPU, memory, and concurrency needed for each request. No manual scaling configuration is required.

<Card title="Automatic Scaling" icon="zap" href="#">
  Resources adjust in real time based on traffic patterns.
</Card>

## Content Delivery Network

The edge CDN caches static assets and runs serverless functions close to users worldwide.

## Best Practices

- Keep preview environments enabled for every pull request.
- Use environment variables to separate development and production secrets.
- Monitor usage through the built-in observability dashboard to optimize Fluid Compute allocations.

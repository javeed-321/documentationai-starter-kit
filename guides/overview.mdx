## Online and In-Person Payments

Stripe Payments lets you accept card and alternative payment methods both online and at physical locations. You can embed checkout flows directly in your site or use terminal hardware for in-person transactions.

<Columns cols={2}>
  <Card title="Online Checkout" icon="globe" href="#">
    Embed a hosted payment page or build a custom integration with the Payments API.
  </Card>
  <Card title="In-Person Terminal" icon="credit-card" href="#">
    Process contactless payments using Stripe Terminal on supported devices.
  </Card>
</Columns>

## Marketplace Connect Flows

Use Connect to onboard third-party sellers and route payments through your platform. The flow typically includes account creation, onboarding, and payout configuration.

<Tabs>
  <Tab title="Standard" icon="users">
    Create connected accounts and collect onboarding information with prebuilt forms.

    ```javascript
    const account = await stripe.accounts.create({
      type: 'custom',
      country: 'US',
      capabilities: { transfers: { requested: true } },
    });
    ```
  </Tab>
  <Tab title="Express" icon="zap">
    Offer a streamlined onboarding experience hosted by Stripe.

    ```javascript
    const account = await stripe.accounts.create({ type: 'express' });
    ```
  </Tab>
</Tabs>

## Custom Revenue Models

Billing and Sigma help you implement subscriptions, usage-based pricing, and advanced reporting.

<Callout kind="info">
  Combine Billing with Connect to charge platform fees on every transaction.
</Callout>

<Expandable title="Subscription example" default-open="false">
  Create a product and price, then subscribe a customer.

  ```javascript
  const subscription = await stripe.subscriptions.create({
    customer: 'cus_example',
    items: [{ price: 'price_monthly' }],
  });
  ```
</Expandable>

## Best Practices

- Always validate webhook signatures before processing events.
- Use Radar to review high-risk payments automatically.
- Test every integration path in test mode before going live.
